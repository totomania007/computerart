## 🎯 ภาพรวม

**Classwork Hub** เป็นเว็บแอปแบบไฟล์เดียว (Multi-file static) สำหรับห้องเรียนออนไลน์ ที่ช่วยให้:

- **ครู** สร้างโพสต์ตัวอย่างงาน, วิดีโอสอน, แรงบันดาลใจ + สร้างใบงาน + ตรวจงานให้คะแนน
- **นักเรียน** ดูใบงาน, ส่งผลงาน, ตรวจสอบคะแนนและคำติชมด้วยตนเอง

ข้อมูลทั้งหมดเก็บใน **localStorage** ของเบราว์เซอร์ — ไม่ต้องมีเซิร์ฟเวอร์, ไม่ต้องมีฐานข้อมูล

## ✨ ฟีเจอร์หลัก

### 📰 ฟีดห้องเรียน (Facebook-style)

| ประเภทโพสต์ | ไอคอน | คำอธิบาย |
|---|---|---|
| ตัวอย่างงาน | 🎨 | โพสต์รูปภาพตัวอย่างงาน |
| วิดีโอ / ตัวอย่างการสร้างงาน | 🎬 | ฝัง YouTube หรืออัปโหลดไฟล์วิดีโอ |
| ขั้นตอนการทำ (How-to) | 📝 | คู่มือทีละขั้น |
| แรงบันดาลใจ | 💡 | ไอเดียและแนวคิด |
| ประกาศ | 📢 | ข่าวสารห้องเรียน |

**สิ่งที่ทำได้:** กดถูกใจ 💜, คอมเมนต์, แชร์

### 📋 ระบบใบงาน

- ครูสร้างใบงานใหม่: ชื่อ, วิชา, รายละเอียด, ขั้นตอน, กำหนดส่ง, คะแนนเต็ม
- **แนบไฟล์** (PDF, เอกสาร)
- **แนบภาพตัวอย่างงาน** (สูงสุด 5 รูป) — ให้นักเรียนเห็นตัวอย่างก่อนทำ
- สถานะอัตโนมัติ: เปิดรับงาน → ส่งแล้ว → ตรวจแล้ว / ต้องแก้ไข

### 📤 ส่งงาน (นักเรียน)

ส่งได้ 3 วิธี:
1. **พิมพ์คำตอบ** ในช่อง textarea
2. **อัปโหลดไฟล์** (PDF/รูปภาพ, ≤2MB)
3. **แปะลิงก์** Google Drive หรืออื่นๆ

ส่งใหม่ได้ถ้าครูให้แก้

### ✅ ตรวจงาน (ครู)

- เลือกใบงาน → เห็นรายชื่อนักเรียนทุกคนที่ส่ง
- ให้คะแนน (1-100) + เขียนคอมเมนต์
- ปุ่มลัด: **👍 ผ่าน** (ให้ 10/10) / **🔄 ให้แก้ใหม่**
- นับจำนวนที่ตรวจแล้ว: "ตรวจแล้ว 3/5"

### 📊 ผลงานของฉัน (นักเรียน)

- สถิติ: จำนวนใบงาน, ส่งแล้ว, ตรวจแล้ว, คะแนนเฉลี่ย
- ดูคะแนนและคำติชมจากครูแต่ละงาน

## 🚀 วิธีติดตั้งและใช้งาน

### วิธีที่ 1: เปิดไฟล์โดยตรง

ดับเบิลคลิก `index.html` ใน Windows Explorer — เปิดในเบราว์เซอร์ได้ทันที

> ⚠️ **ข้อจำกัด:** วิธีนี้ใช้ได้เฉพาะบนเครื่องที่สร้างไฟล์ เพราะข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น

### วิธีที่ 2: เซิร์ฟเวอร์ท้องถิ่น (แนะนำสำหรับ development)

```bash
# Python
python -m http.server 8000 --bind 127.0.0.1

# Node.js (ต้องติดตั้ง npm)
npx serve .

# PHP
php -S 127.0.0.1:8000
```

เปิด `http://127.0.0.1:8000`

### วิธีที่ 3: Deploy ขึ้นคลาวด์ (ใช้งานจริง)

อัปโหลดทั้งโฟลเดอร์ขึ้น:
- **GitHub Pages** (ฟรี)
- **Netlify** (ฟรี)
- **Vercel** (ฟรี)

> 📌 เมื่อ Deploy แล้ว นักเรียนเข้าถึงได้จากทุกเครื่อง แต่ข้อมูลยังแยกตามเบราว์เซอร์ของแต่ละคน

## 📖 คู่มือใช้งาน

### 🧑‍🏫 โหมดครู (Teacher)

#### สร้างโพสต์

1. ไปที่ **ฟีดห้องเรียน**
2. กดปุ่ม **+ สร้างโพสต์**
3. เลือกประเภท (ตัวอย่างงาน/วิดีโอ/แรงบันดาลใจ/ประกาศ)
4. กรอกหัวข้อ + เนื้อหา
5. แนบรูปภาพ (ไม่บังคับ) + ลิงก์ YouTube หรือไฟล์วิดีโอ
6. กด **โพสต์**

#### สร้างใบงาน

1. ไปที่เมนู **ใบงาน**
2. กดไทล์ **+ สร้างใบงานใหม่**
3. กรอก:
   - ชื่อใบงาน (บังคับ)
   - วิชา
   - คะแนนเต็ม (1-100)
   - กำหนดส่ง
   - รายละเอียดงาน
   - ขั้นตอน/ข้อกำหนด
   - ไฟล์แนบ (PDF/เอกสาร)
   - **🖼️ ภาพตัวอย่างงาน** (สูงสุด 5 รูป)
4. กด **สร้างใบงาน**

#### ตรวจงาน

1. ไปที่เมนู **ตรวจงาน**
2. เลือกใบงานที่ต้องการตรวจ
3. ดูงานที่นักเรียนส่งมา (ชื่อ, คำตอบ, ไฟล์, ลิงก์)
4. ให้คะแนน + เขียนคอมเมนต์
5. กด **💾 บันทึกคะแนน**
6. ปุ่มลัด: **👍 ผ่าน** (ให้ 10/10) / **🔄 ให้แก้ใหม่** (reset คะแนน)

---

### 🎓 โหมดนักเรียน (Student)

#### ดูใบงานและส่งงาน

1. สลับเป็น **นักเรียน** ที่ด้านบนขวา
2. ใส่ชื่อ-นามสกุล (ครั้งแรก)
3. ไปที่เมนู **ใบงาน**
4. กดเลือกใบงาน → อ่านรายละเอียด + ดูภาพตัวอย่าง
5. กดปุ่ม **ส่งงาน**
6. เขียนคำตอบ / อัปโหลดไฟล์ / แปะลิงก์
7. กด **ส่งงาน**

#### ตรวจสอบคะแนน

1. ไปที่เมนู **ผลงานของฉัน**
2. ดูสถิติ: ส่งแล้ว / ตรวจแล้ว / คะแนนเฉลี่ย
3. เลือกงานที่ต้องการ → เห็นคะแนนและคำติชมจากครู

## 🎨 คุณลักษณะดีไซน์ Neo Brutalism

| คุณลักษณะ | ค่า |
|---|---|
| **Border** | 3px solid #000 ทุก component |
| **Shadow** | Offset สี: `4px 4px 0 #000` (ไม่เบลอ) |
| **มุม** | 0-4px (แหลม) |
| **สีหลัก** | ฟ้า `#0066FF` |
| **สีเสริม** | เขียว `#00D26A`, ชมพู `#FF6B9D`, เหลือง `#FFDE59` |
| **Hover** | `translate(-2px,-2px)` + shadow ใหญ่ขึ้น |
| **Active** | `translate(1px,1px)` + shadow เล็กลง |
| **Avatar** | สีเดียว + มุมแหลม + border ดำ |
| **Header** | ขาว + border ดำ + shadow 4px |
| **Font** | Mitr (หัวข้อ) + Prompt (เนื้อหา) — รองรับภาษาไทย |

## 📁 โครงสร้างไฟล์ละเอียด

### `index.html`

โครงสร้าง HTML หลัก — เชื่อม CSS และ JS ทั้งหมด:

- **Header:** โลโก้ + เมนู nav + สลับโหมดครู/นักเรียน
- **Screen Feed:** ฟีดโพสต์แบบ Facebook
- **Screen Assignments:** รายการใบงาน (Bento Grid)
- **Screen Results:** ผลงานของฉัน (สถิติ + รายละเอียด)
- **Screen Grading:** ตรวจงาน (เลือกใบงาน → ให้คะแนน)
- **Modals:** สร้างโพสต์, สร้างใบงาน, ดูรายละเอียด, ส่งงาน, lightbox

### `js/utils.js`

ตัวช่วยทั่วไปที่ใช้ทุกไฟล์:

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `uid()` | สร้าง ID ไม่ซ้ำ |
| `esc(s)` | ป้องกัน XSS |
| `fmtDate(iso)` | จัดรูปแบบวันที่ภาษาไทย |
| `toast(msg)` | แสดงข้อความแจ้งเตือน |
| `readFile(file, cb)` | อ่านไฟล์เป็น data URL (≤2MB) |
| `openLightbox(dataUrl, name)` | เปิดภาพเต็มจอ |
| `svgPic(text, a, b)` | สร้างรูป placeholder จาก SVG |
| `ICONS` | ไอคอน SVG ทั้งหมด (Lucide style) |
| `POST_META` | ข้อมูลประเภทโพสต์ |

### `js/state.js`

จัดการข้อมูลและ localStorage:

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `load()` | โหลดข้อมูลจาก localStorage |
| `save()` | บันทึกลง localStorage |
| `seed()` | สร้างข้อมูลตัวอย่างครั้งแรก |
| `defaultData()` | โครงสร้างข้อมูลว่าง |

### `js/feed.js`

ระบบฟีด Facebook:

- `renderFeed()` — แสดงโพสต์ทั้งหมด
- `toggleLike(id)` — กดถูกใจ/เลิกถูกใจ
- `addComment(id)` — เพิ่มคอมเมนต์
- `sharePost(id)` — แชร์ (copy link)

### `js/assignments.js`

ระบบใบงาน:

- `renderAssignments()` — แสดงรายการใบงานแบบ Bento Grid
- `openDetail(id)` — ดูรายละเอียด + ภาพตัวอย่าง
- `openSubmitModal(id)` — เปิดฟอร์มส่งงาน
- `submitWork()` — บันทึกงานที่ส่ง

### `js/grading.js`

ระบบตรวจงาน:

- `renderGradingSelect()` — เลือกใบงาน
- `renderGradingArea()` — แสดงงานที่ส่งมา + ให้คะแนน

### `js/results.js`

ผลงานของฉัน:

- `renderResults()` — แสดงสถิติ + คะแนน + คำติชม

### `js/modals.js`

ฟอร์มสร้าง:

- `openPostModal()` / `savePost()` — สร้างโพสต์
- `openAssignModal()` / `saveAssignment()` — สร้างใบงาน (รองรับภาพตัวอย่าง)
- `onPickMultipleFiles()` — เลือกหลายไฟล์

### `js/main.js`

จุดเริ่มต้น:

- โหลดข้อมูล → render → ตั้งค่า navigation
- `showScreen(name)` — สลับหน้าจอ
- `render()` — render ทุกส่วน

## ⚙️ การปรับแต่ง

### เปลี่ยนธีมสี

แก้ CSS Variables ใน `css/styles.css` ส่วน `:root`:

```css
:root {
  --primary: #0066FF;      /* สีหลัก */
  --secondary: #00D26A;    /* สีเสริม */
  --accent: #FF6B9D;       /* สีเน้น */
  --yellow: #FFDE59;       /* สีเหลือง */
  --bg: #FFFFFF;           /* พื้นหลัง */
  --fg: #000000;           /* สีตัวอักษร */
  --border-w: 3px;         /* ความหนา border */
  --shadow: 4px 4px 0 #000; /* เงา offset */
}
```

### เปลี่ยนฟอนต์

แก้ `<link>` ใน `index.html` แล้วอัปเดต CSS:

```html
<link href="https://fonts.googleapis.com/css2?family=Sarabun:wght@400;600;700&family=Kanit:wght@400;600;700&display=swap" rel="stylesheet">
```

```css
body { font-family: 'Sarabun', sans-serif; }
h1,h2,h3,h4 { font-family: 'Kanit', sans-serif; }
```

### ปรับขนาดไฟล์สูงสุด

แก้ค่า `MAX_FILE` ใน `js/utils.js`:

```javascript
const MAX_FILE = 5 * 1024 * 1024; // เปลี่ยนเป็น 5MB
```

## ⚠️ ข้อจำกัด

| ข้อจำกัด | คำอธิบาย | วิธีแก้ |
|---|---|---|
| **ข้อมูลในเครื่องเดียว** | เก็บใน localStorage — นักเรียนคนละเครื่องเห็นข้อมูลคนละชุด | Deploy เป็นเว็บจริง + ใช้ database |
| **พื้นที่ 5MB** | localStorage จำกัด ~5MB — รูป/ไฟล์ใหญ่จะเต็ม | ใช้ลิงก์ Google Drive แทนการอัปโหลด |
| **ไม่มี login** | ใครก็เปิดดูได้ ไม่มีการยืนยันตัวตน | เพิ่ม auth (Firebase/Supabase) |
| **ไม่มี real-time** | ต้อง refresh หน้าเพื่อดูข้อมูลใหม่ | ใช้ WebSocket / polling |
| **ไม่รองรับ Offline** | ต้องต่ออินเทอร์เน็ตเพื่อดูฟอนต์ | เพิ่ม Service Worker |
